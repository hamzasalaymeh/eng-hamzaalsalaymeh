# Portfolio Redesign 2026

Direction: Digital Engineering / BIM / Automation.

## Changes
- Replaces the conservative navy/gold visual language with a deep technical interface using cyan and violet signals.
- Removes visible project numbering through the redesign layer.
- Elevates BIM, digital delivery, coordination, data, and automation as the core professional narrative.
- Keeps existing project content and imagery intact while modernizing presentation.
- Preserves bilingual Arabic/English behavior and responsive layout.
- Reuses existing certificate imagery to avoid duplicate assets.

## Deployment
`index.html` loads `assets/redesign-2026.css` after the embedded legacy styles, making the redesign isolated and reversible.
